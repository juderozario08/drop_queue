# Ruby Explanation Rule

When generating, reviewing, or explaining Ruby on Rails code, you must assume the user is a complete beginner to Ruby.
- Provide a strict, line-by-line breakdown of any new code presented.
- Explain all Ruby-specific syntax, symbols (e.g., colons `:`, pipes `|`, bang methods `!`, blocks `do...end`, implicit returns).
- Demystify any "Rails Magic" (conventions over configuration, Active Record methods) so the user understands exactly what is happening under the hood without making assumptions about their prior knowledge.
